# North Star Family-Tree Packets

These PDFs are client-provided reference packets for the document-preparation workflow. They are image-based PDFs, so the first implementation pass used rendered-page inspection instead of text extraction.

## Files

- `deborah-cheatham-est-family-tree.pdf`
  - Complex example.
  - Five pages.
  - Contains a larger heir/contact set and more probate, mortgage, adverse-possession, and ownership-history nuance.
- `constance-e-white-est-family-tree.pdf`
  - Simpler example.
  - Four pages.
  - Contains the same report structure with fewer contacts and fewer blockers.

## Report Structure To Preserve

- Title and date-added metadata.
- Property address and owner / estate identity.
- Offer / Profit table with As-Is Value, Taxes Due, Liens, Mortgages, Selling Costs, Probate Costs, Partition Costs, Post Equity Value, Amount per heir, number of heirs, Profit, Offer per heir, Min Profit, and the `$100,000 Net` benchmark row.
- Owner DOB / DOD, obituary status, and public-record source notes.
- Back Story narrative.
- Deed, title, tax, mortgage, probate, and adverse-possession notes.
- Heir/contact matrix with relationship, address history, phone numbers, email, and confidence/source notes.
- Export posture for Podio, Google Docs, and Google Sheets.

The in-app Dossier rail should render a cleaner, more comprehensive version of this shape from the live lead packet while keeping all unverified values visible as review items.
